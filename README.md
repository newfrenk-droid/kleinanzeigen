# Kleinanzeigen автоответчик

Бот отвечает за вас на **входящие** сообщения на Kleinanzeigen. Каждый аккаунт работает
в своём профиле антидетект-браузера **Vision** со своим прокси. Бот понимает, по какому
вашему объявлению написал человек, и выбирает под этот товар нужный текст автоответа.
Всё управляется через веб-панель.

## Что умеет

- **Аккаунты по куки + прокси.** Куки принимаются в JSON (Cookie-Editor, EditThisCookie, экспорт Vision),
  в формате Netscape `cookies.txt` или строкой `name=value; ...`. Прокси: `http://user:pass@host:port`,
  `socks5://host:port`, `host:port:user:pass`, `host:port`.
- **Профиль в Vision.** При первом запуске аккаунта бот сам создаёт в Vision прокси и профиль
  (с актуальным отпечатком), импортирует куки, запускает профиль и подключается к нему.
- **Отвечает только на входящие.** Ответ уходит, только если последнее сообщение в диалоге
  от другого пользователя. Диалоги, где вы сами писали продавцу (вы покупатель), бот не трогает.
  Если вы уже ответили сами, бот тоже молчит.
- **Распознаёт товар.** Для каждого диалога сохраняется, кто написал, по какому объявлению
  (название, ID, цена) и что именно. Это видно на странице «Диалоги».
- **Редактируемые шаблоны.** Тексты меняются в панели и применяются сразу, перезапуск не нужен. Шаблон можно привязать:
  - к конкретному объявлению (по ID);
  - к ключевым словам в названии товара (`iphone, airpods`);
  - к конкретному аккаунту или ко всем сразу.

  Переменные: `{buyer_name}`, `{ad_title}`, `{ad_price}`, `{ad_id}`, `{ad_url}`, `{account_name}`, `{message}`.
  Если разделить текст строками `---`, бот будет каждый раз выбирать случайный вариант.
- **Похоже на человека.** Перед ответом бот делает случайную паузу, открывает диалог и набирает
  текст посимвольно. Все интервалы настраиваются.

## Установка

Нужны Python 3.10+ и установленное приложение Vision. Vision должно быть запущено,
пока работает бот: через его локальный API бот открывает профили.

```bash
python -m venv .venv
# Windows: .venv\Scripts\activate    Linux/macOS: source .venv/bin/activate
pip install -r requirements.txt
python run.py
```

Откройте http://127.0.0.1:8000.

> Отдельно ставить браузер для Playwright не нужно: бот подключается к браузеру Vision по CDP.

Чтобы закрыть панель паролем, задайте переменные окружения `PANEL_PASSWORD` и, по желанию, `PANEL_USER`
(по умолчанию `admin`). По умолчанию панель слушает только `127.0.0.1`. Адрес и порт меняются
переменными `HOST` и `PORT`.

## Первый запуск

1. **Настройки → Vision:** укажите API-токен (в Vision: Настройки → API) и ID папки, в которой бот будет создавать профили.
2. **Аккаунты → Добавить аккаунт:** название, куки, прокси.
3. **Шаблоны ответов:** отредактируйте общий шаблон и при желании добавьте шаблоны под конкретные товары.
4. Нажмите **▶ Старт** у аккаунта. Что происходит, видно в «Логе», входящие и ответы — в «Диалогах».

Если Kleinanzeigen отправил аккаунт на страницу входа, статус станет «куки недействительны».
Вставьте новые куки в карточке аккаунта и запустите его снова.

## Как это работает

```
Панель (FastAPI) ──► воркер аккаунта ──► Vision API: создать прокси/профиль, импорт куки
                                      └► Vision local API: /start → порт CDP
                                         └► Playwright connect_over_cdp
                                            ├ открывает «Nachrichten», перехватывает список диалогов,
                                            │ токен и userId из запроса самой страницы
                                            ├ детали диалога: fetch() внутри страницы (через прокси профиля)
                                            ├ решает: входящее? наш товар? уже отвечали?
                                            └ открывает диалог, набирает текст, «Senden»
```

Все запросы к Kleinanzeigen идут изнутри браузера Vision, то есть через прокси профиля, а не с вашего IP.

Режимы (раздел «Настройки»):

| Настройка | Значение |
|---|---|
| Режим ответа | `once` — один автоответ на диалог; `every` — на каждое новое входящее |
| Способ отправки | `ui` — через окно диалога; `api` — POST в messagebox API |
| Только по нашим объявлениям | не отвечать в диалогах, где вы покупатель |

## Если Kleinanzeigen что-то поменяет

Адреса страниц и API, а также CSS-селекторы поля ввода и кнопки «Senden» вынесены в
**Настройки → Kleinanzeigen**. Код при этом менять не нужно. JSON-ответы разбираются
с запасом: проверяются несколько вариантов названий полей.

## Тесты

```bash
pip install -r requirements-dev.txt
pytest
```

`tests/test_e2e.py` поднимает реальный Chromium и локальную имитацию Kleinanzeigen и Vision,
затем проверяет весь цикл: от чтения входящих до отправки ответа.

## Структура

```
app/cookies.py       разбор куки
app/proxy.py         разбор прокси
app/vision.py        клиент Vision (облачный + локальный API)
app/kleinanzeigen.py диалоги, сообщения, объявления, отправка
app/replies.py       выбор шаблона под товар и подстановка переменных
app/worker.py        цикл аккаунта и менеджер запуска
app/web.py           веб-панель
app/db.py            SQLite (data/bot.db)
```
